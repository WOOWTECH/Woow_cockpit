# 應用軟體

Cockpit「工具 → 應用軟體」提供使用者導向的服務卡片與詳情。沿用服務管理 helper 及 Cockpit 既有管理員授權；沒有新增 API 或授權方式。清單按已設定的管理範圍取得 systemd 服務和容器，將已識別應用的元件分組，其餘可管理的本機／Quadlet 服務以獨立卡片顯示。沒有 systemd 對應服務的容器列於「其他服務」，可前往容器管理操作。屬未設定擁有者的服務及一般未註冊程式不會被自動發現；狀態為主要服務的 systemd 狀態，不代表全部功能健康。

卡片提供主要服務的啟動、停止與重啟；進階區可查看個別元件和使用既有服務／容器管理。操作前會重新讀取服務狀態並要求確認；日誌可選擇個別服務並顯示最近紀錄。此版不提供應用組態編輯、整組啟停、安裝、升版或備份，應用入口僅在已驗證的連線方式下顯示。各應用原有登入與授權仍然適用。

應用卡片中出現的服務名稱及分組規則不帶主機密碼；服務日誌可能包含機密，僅限具 Cockpit 管理員權限的使用者讀取。測試與部署見專案根目錄的管理工具。VPN 與非預設位址的應用入口需要另外驗證，不要直接推斷服務可以跨網路使用。
