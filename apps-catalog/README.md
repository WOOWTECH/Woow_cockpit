# 應用軟體

Cockpit「工具 → 應用軟體」提供使用者導向的服務卡片與詳情。沿用服務管理 helper 及 Cockpit 既有管理員授權；沒有新增 API 或授權方式。清單按已設定的管理範圍取得 systemd 服務和容器，將已識別應用的元件分組，其餘可管理的本機／Quadlet 服務以獨立卡片顯示。沒有 systemd 對應服務的容器列於「其他服務」，可前往容器管理操作。屬未設定擁有者的服務及一般未註冊程式不會被自動發現；狀態為主要服務的 systemd 狀態，不代表全部功能健康。

應用提供整組啟動與停止；依已確認的明確元件清單及 systemd 依賴順序處理，操作前會列出元件並要求確認。組外依賴仍在使用時會拒絕停止；部分失敗時停止後續操作並顯示結果。進階區可查看個別元件和使用既有服務／容器管理。日誌可選擇個別服務並顯示最近紀錄。此版不提供應用組態編輯、安裝、升版或備份，應用入口僅在已驗證的連線方式下顯示。各應用原有登入與授權仍然適用。

應用卡片中出現的服務名稱及分組規則不帶主機密碼；服務日誌可能包含機密，僅限具 Cockpit 管理員權限的使用者讀取。測試與部署見專案根目錄的管理工具。VPN 與非預設位址的應用入口需要另外驗證，不要直接推斷服務可以跨網路使用。

介面使用 Material Design Icons 路徑資料，授權文字見同目錄 MDI-LICENSE.txt。

應用頁使用本機字型與 Material Design Icons，提供淺色及深色配色；會跟隨 Cockpit 的「風格」選擇，選擇「預設值」時跟隨裝置的系統主題。畫面遵循 woowtech 的藍色、圓角與簡潔留白，不依賴外部字型或圖片 CDN。Gira Sans 和文鼎授權字型目前分別以 Poppins 和 Noto Sans TC 替代。
