# apporo brand materials

The project owner supplied these existing materials for the apporo edition.
The company attribution in the source projects is **APPORO UNION INC.**
Brand marks and trademarks are not relicensed under this repository's source
code license. No general trademark-use or standalone redistribution license is
granted here.

`asset-provenance.json` records each unmodified asset's SHA-256 and source.
The two company SVGs were additionally verified byte-for-byte against
`WOOWTECH/Woow_apporo_ha_app` at commit
`50203b0f12e9` (the full commit is recorded in the manifest).
Smart application icons come from `WOOWTECH/woowtech-smart` at
`fb96335087d944b13e99bf67f511b760eb868b3c`.

The SVG wordmark is outlined original artwork, not a new typeset logo. This
edition includes no proprietary font files. UI typography uses the operating
system's font stack.

The management UI adapts existing Smart spacing/radius values and the
Assistant's accessible dark primary/on-primary color pair. Those adaptations
are implementation choices for this management interface, not a claim that
Apporo has a single published corporate design system. A hover color was not
established in the source materials, so it uses the primary color.

`apporo 設備管理` is this edition's descriptive UI title. Existing products
`Apporo aiot`, `Apporo smart`, `Apporo platform` (ERP) and `Apporo Assistant`
retain their separate meanings. This package does not rename Pi's agent engine
or claim to install those separate mobile/desktop products.
