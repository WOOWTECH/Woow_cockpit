# 尚待實作的產品功能

目前交付的是品牌化 Cockpit、原生管理頁與部署來源。下一階段的獨立「備份與還原」套件仍需另行實作。

客戶所需的流程：選擇或上傳備份檔 → 顯示服務／備份時間／相容版本 → 檢查容量與完整性 → 確認還原 → 顯示進度與結果。

建議驗收範圍：

1. **服務備份規格**：定義必要設定、密鑰、資料卷和資料庫的一致性；提供各應用 adapter。不能用運行中資料庫目錄的任意壓縮檔代替一致性備份。
2. **還原前檢查與保護**：驗證封存路徑、檔案雜湊、版本、可用空間及必要服務；先備份現況，再依相依順序停止／還原／啟動。
3. **可靠工作執行器**：使用受控權限與 systemd 工作，瀏覽器關閉後仍可追蹤；提供可理解的進度、結果與重試／復原方式。
4. **跨設備演練**：以全新機器驗證匯入、服務健康、密鑰／權限、資料一致性及失敗回復。沒有演練前不宣稱「無痛還原」。

客戶自行線上升級不是目前第一階段要求。Cockpit package 機制可承載獨立頁面，但本身不會自動提供上述備份引擎或 HA Supervisor 的服務生命週期管理。
