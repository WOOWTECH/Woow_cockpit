# 建置現況與驗證界線

紀錄日期：2026-11-12。這是參考主機的建置紀錄，不代表每台新設備已做相同驗收。

## 參考版本

| 元件 | 版本／狀態 |
| --- | --- |
| Ubuntu | 24.04.4 LTS |
| Cockpit 核心與系統／網路／儲存／更新擴充 | 362-1~bpo24.04.1 |
| cockpit-podman | 124-1~bpo24.04.1 |
| Podman | 4.9.3+ds1-1ubuntu0.2 |

| 代理、帳號、憑證 | 設備個別設定，未收錄於來源 |

base1 manifest 的 API 版本不能當 Cockpit 套件版本；安裝程式從 dpkg 狀態取得版本。此清單記錄當時環境，bootstrap 會使用 backports 當時可用版本。

## 目前設計

使用使用者提供的正式 SVG，主題藍 `#6183FC`。最新要求是全白底，已移除頁面底圖與灰色外框；實際卡片仍保留20px 圓角。字型為 Poppins、Outfit、Noto Sans TC；Yellowtail 檔案供品牌支援但沒有強加裝飾字到管理表格。既有 Cockpit 圖示、警示色與終端機配色保留。

12 個原生頁面及獨立畫面參考頁已套用樣式。更新頁在前次視覺巡檢中仍處於 PackageKit 載入；歷史指標提示需要 PCP。未宣稱這兩項後端能力完成。

## 已執行的視覺驗證

- 初次：12 個原生頁面與圖集，1440／1024／768／390px，共52組畫面檢查。
- 排版修正後：總覽、Podman、服務、指標、帳號各5種寬度（加360px），圖集另5種，共30組，未發現文件橫向溢出。
- 互動：映像展開／收合、首末列選單、手機選單、清單捲到末筆、群組展開／收合、帳號與服務搜尋。
- 全白底修正後：12個原生頁、shell、1024／390px總覽，共15組頁面表面檢查；白底、藍色、卡片圓角及文件寬度符合設定。
- 當時本機圖集17張圖片載入、手機長圖及連結已檢查。公開來源不攜帶那些含主機資訊的截圖；新設備以自己的畫面重建。

以上是介面與指定互動驗證。沒有藉此宣稱映像刪除、服務重啟、網路重新配置、套件升級或完整還原通過。實機截圖、帳號、IP、machine-id、原始日誌與瀏覽器登入狀態留在來源主機，不公開發布。

本次封裝另外加入暫存根目錄安裝／回退測試、圖集無截圖與有截圖測試、來源資產檢查，測試方法見 [testing.md](testing.md)。
