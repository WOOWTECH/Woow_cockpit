## 目前設計

使用使用者提供的正式 SVG，主題藍 `#6183FC`。最新要求是全白底，已移除頁面底圖與灰色外框；實際卡片仍保留20px 圓角。字型為 Poppins、Outfit、Noto Sans TC；Yellowtail 檔案供品牌支援但沒有強加裝飾字到管理表格。既有 Cockpit 圖示、警示色與終端機配色保留。

12 個原生頁面及獨立畫面參考頁已套用樣式。更新頁在前次視覺巡檢中仍處於 PackageKit 載入；歷史指標提示需要 PCP。未宣稱這兩項後端能力完成。

## 2026.11.12.2：實際服務管理

已部署「系統 → 服務管理」，登入管理帳號並取得管理員權限後，預設載入設定的應用擁有者，可切換本機系統。新頁使用原有全白品牌樣式；本輪沒有重新設計既有原生頁。

當次盤點為287個使用者服務，其中63個 Quadlet、28個本機自訂單元；54個容器中48個有 systemd 關聯。這是包含已停止單元的盤點，不能當成啟用應用數。服務支援搜尋、篩選、分頁、詳細資料、日誌及單一服務啟動／停止／重新啟動。6個沒有單元關聯的容器在新頁提供唯讀清單和原生 Podman 入口。

### 實際操作驗證

- 從 Cockpit 瀏覽器操作三個臨時單元：本機系統服務、一般使用者服務、使用者 Quadlet。
- 共11次真實啟停／重啟，逐次以 systemd 狀態、PID及日誌交叉確認；取消確認視窗沒有操作。Quadlet 停止後容器移除，服務仍在清單且可再啟動。
- 23項服務操作、權限及版面檢查通過；桌面1440／1024與手機390／360px沒有文件橫向溢出，沒有頁面 JavaScript 例外。
- 部署最後版本後重新登入，7項讀取檢查通過：未授權資料隔離、預設擁有者、系統範圍、正式容器與單元對應、桌面／手機版面、原生頁手動選擁有者。
- 測試單元、容器和臨時系統單元已移除。Home Assistant、EMQX、n8n、Nextcloud、Odoo、LiteLLM、Hermes、Omnigent、OpenDesign、code-server、Headscale、Cloudflare Tunnel 的主單元仍為 active。本輪未對這些正式應用執行停機或完整業務驗收。
